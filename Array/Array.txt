          4. Searching - Finding an element in the array.
              1. Linear Search (Sequential Search)
                iteam search one by one
                 Use: Works on unsorted or sorted arrays.
                 Time Complexity: O(n)
                How it works: Goes through each element one-by-one until the target is found.
               
               2. Binary Search
                  Use: Works only on sorted arrays.
                  Time Complexity: O(log n)
                  How it works: Repeatedly divides the array in half to find the target.
              
              3. Index Sequential Search : Index Sequential Search is a searching algorithm
               that combines the efficiency of binary search on an index table with 
               sequential search on data blocks. It’s more efficient than linear search and 
               works best when data is sorted.
                1. Divide the array into blocks.
                2. Create an index table with the last element of each block and its 
                starting index.
                3. Search the index table to find the block that may contain the element.
                4. Perform linear search within the block.
            
            4 Interpolation Search :Interpolation Search is an improved variant of
             Binary Search used for uniformly distributed sorted arrays.
             Instead of always checking the middle, it tries to guess where the element
              might be using the formula:
              pos = low + ((key - arr[low]) * (high - low)) / (arr[high] - arr[low])


          5. Sorting - Arranging elements in a specific order.  
           1. Bubble sort : How It Works: Repeatedly compares adjacent elements and swaps 
                            them if they are in the wrong order.
                            Best For: Simple, small datasets.
                            
                            Stable Sort: ✅ Yes

             2. Selection Sort : How It Works: Repeatedly selects the minimum element and
                                 places it at the beginning.
                                 Best For: Learning purposes; not efficient for large 
                                            datasets.
                                  Stable Sort: ❌ No               
             
             3. Insertion Sort : How It Works: Builds the sorted array one item at a time
                                 by inserting elements in the correct position.
                                 Best For: Nearly sorted arrays or small datasets.
                                 Stable Sort: ✅ Yes
             
             4. Merge Sort : How It Works: Divides the array into halves, sorts each half,
                             and then merges them.
                             Best For: Large datasets; guarantees O(n log n).
                             Stable Sort: ✅ Yes

             5️.Quick Sort : How It Works: Selects a pivot, partitions the array into two 
                            halves, and recursively sorts them.
                            Best For: General-purpose; performs well in practice.
                            Stable Sort: ❌ No

             6. Shell Sort : Shell Sort is an optimized version of Insertion Sort.
             It works by comparing elements far apart (using a gap) and reducing the gap 
             step-by-step until the final pass is a simple Insertion Sort.
             Start with a large gap (e.g., n/2).
             Sort elements that are gap distance apart.
             Gradually reduce the gap (e.g., gap = gap/2).
             Final pass is a standard Insertion Sort when gap = 1.
             Best For:Medium-sized arrays where performance and space efficiency are both important.
             Stable Sort: ❌
