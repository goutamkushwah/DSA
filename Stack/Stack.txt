Stack - A Stack is a linear data structure that follows a particular order in which the 
        operations are performed. The order may be LIFO(Last In First Out) or 
        FILO(First In Last Out). LIFO implies that the element that is inserted last, 
        comes out first and FILO implies that the element that is inserted first, comes 
        out last.
        LIFO: Last In First Out
              → The element inserted last is the first one to be removed.
                                      -----> 5 (POP)
                (push) 5 ---> |   5   |   ← top
                              |   4   |
                              |   3   |
                              |   2   |
                              |   1   |

operation -1. push()	Adds (inserts) an element to the top of the stack.
        2. pop()	Removes (deletes) the top element of the stack.
        3. peek() / top()	Returns the top element without removing it.
        4. isEmpty()	Checks whether the stack is empty.
        5. isFull()	(For static stack) Checks whether the stack is full (used in array stack).
        6. Size

Note - 🔍 Can We Perform Searching and Sorting in a Stack?
✅ Technically Yes, But Not Efficiently
Stacks are not designed for searching or sorting — they are LIFO structures where only the top element is accessible directly. However, you can implement searching and sorting using extra stacks or temporary data structures.

🔎 1. Searching in Stack
You can search by popping each element until you find the target.

But this destroys the stack, unless you store popped items in a temporary stack and then push them back.
